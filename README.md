# Drug Awareness — Infographic Design

## About the Project
This project explores drug awareness through information design and visual storytelling. It focuses on presenting information through visual elements and structured layouts to make the subject more engaging and accessible.

## Project Details
- **Project Type:** Infographic / Information Design
- **Category:** Visual Communication
- **Tool:** Figma
- **Format:** Interactive Prototype

## Design Objectives
- Communicate information through visual storytelling.
- Organize content using visual hierarchy and layout.
- Explore digital information design and interactive presentation.
- Make complex information easier to understand.
